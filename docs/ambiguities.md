# 规范歧义清单（ambiguities.md）

| 项 | 内容 |
|---|---|
| 文档版本 | **v0.3**（2026-10-09；v0.3 加入 vnpy 差分实测结论，见 `docs/operators.md` §6） |
| 依据 | 设计文档 §6.1「可判定性」、§6.2、§6.8、§9 R2 |
| 覆盖范围 | **算子层（L1）已完成全部决策**；因子层（L2/L3）待 M3 逐条记录 |

> 设计文档的硬性要求：**有歧义的因子一律标 `ambiguous`，不得标 `verified`**（§9 R2）。
> 本文档是《歧义清单》的载体，与 `docs/deviations.md`（偏差清单）配对使用。

**`ambiguous` 的判定标准（本项目的显式划线）**：只有当**论文规范本身未定**、
且不同读法会改变**因子含义/数值**时，才把因子标为 `ambiguous`（历史上 A4/A11/A20 共 27 个因子；**2026-10-10 经 L-B 定案后已全部清零**，见 §4.1）。
「缺失值/预热/并列/ddof 等库级约定」即使论文未写，也按**已决策**处理（A1/A7/A8/A16/A18/A22/A23），
因为它们不改变公式的含义，只是本库的显式工程约定——两类都写进本文档，但标签不同。

## 0. 为什么要分类记录

「正确」必须相对于**一个选定的规范**来定义。论文（arXiv:1601.00991）是**事实规范但不是官方标准**，
它对算子口径没有穷尽定义，因此存在三类情形：

| 分类 | 含义 | 处置 |
|---|---|---|
| **可判定·已决策** | 有唯一数学定义，只是社区口径分歧 | 做**显式决策**（参数或文档），并用独立权威实现对拍；**不影响** `verified` 判定 |
| **待决（因子层）** | 论文表述不足以唯一确定实现 | M3 逐条记录；相关因子进 `ambiguous` |
| **无法判定** | 数据源/平台差异导致原理上不可判定 | 只能如实记录，不得伪装成验证通过 |

## 1. 算子层（L1）：6 个歧义点 —— 全部已决策

算子层可 100% 判定（有唯一数学定义 + 独立权威实现），因此这些是**「已决策」而非「待决」**。
决策细节与理由见 `docs/operators.md` §3；此处记录「歧义是什么、决策依据属于哪一级规范」。

|---|---|---|---|---|---|

以下是**已知会出现的**歧义类别（设计文档 §6.7、§8.4 提及），尚未逐条判定——因为因子还没写。
M3 时必须对 101 个因子逐个给出：规范条文 → 可判定性 → 处置（`verified`/`partial`/`ambiguous`）。

| 类别 | 典型问题 | 影响 |
|---|---|---|
| 数据字段定义 | ~~`adv20` 用 `volume` 还是 `amount`？~~ → **已由论文定案：`adv{d}` 是平均每日「美元成交额」，A 股取 `amount`（元）**，用 volume 属近似（见 A14）。剩余：`cap` 用总市值还是流通市值？单位（万元/元）？ | 因子数值整体缩放或口径偏移（45 个因子涉 adv） |

| 条件分支边界 | `x >= 1` 还是 `> 1`；`<= 0.05` 还是 `< 0.05`（vnpy 自述在这两处做了改动） | 少数样本归属不同 |

| 论文笔误嫌疑 | 个别公式的括号/符号在论文中可能有误 | 处置为**偏离**（剔除，不进统计，§6.3） |
| 复权与 PIT | 前复权口径、行业 as-of、成分股时点 | 前视污染风险（§9 R3） |
| 平台口径 | BRAIN Fast Expression 的算子细节 | 只能做「行为对齐」（单调性/相关性），不能数值相等（§2.3） |

## 4. M4 差分 + L-B 定案（对歧义清单的影响）

### 4.1 L-B 定案（2026-10-10，`operators.md` §3.13）

先落地的是**规范歧义**（A4/A11/A20）；随后按**完整文档的算例**又落地了三处默认口径（A1/A2/A3 + `decay_linear` 缺失值）：

| 原歧义 | 定案依据（BRAIN 原文要点） | 结果 |
|---|---|---|
| **A4** argmax 基准 | "If today's value is the maximum, **returns 0**" | 默认翻转为 `days_ago`；6 个因子（1/57/60/96/98/100）随之定案 |
| **A11** decay 方向 | "averaging **recent** values and reducing the impact of **older** data" | 本库默认正确；22 个因子定案 |
| **A20** 中缀 `^` | `power`（可丢符号）与 `signed_power`（保号）是两个算子 | 论文 `^` → `power`；alpha48 修复、alpha90 两读法同值 |

⇒ `ambiguous` 标签由 **27 个清零为 0**，101 个因子一律 `partial`（`verified` 仍待 M5 golden 快照）。

第二轮（同日）：A1（ddof→0）、A2/A3（归一化→`(名次−1)/(n−1)`）、`decay_linear` 缺失值（→官方稀疏 NaN→0）
也已按官方算例落地 —— 它们不是「歧义」而是**本库默认值原先与官方不同**，修正后与官方语义一致。

### 4.2 M4 因子级差分实测（定案前的归因素材）

对拍范围 **82/101**（19 个无参照，见 U5）；语义归一化后 **64 逐点一致 + 18 已归因 + 0 待查**。

| 歧义项 | M4 实测结论 |
|---|---|
| **A11** `decay_linear` 方向 | 22 个可比因子必须切到 `oldest_first` 才与 vnpy 一致 ⇒ **实质口径差异已定量确认**（最高风险项，仍待 BRAIN 原文裁决） |
| **A7** `rank` 并列 | vnpy 取 `method="min"`，需开对齐开关 ⇒ 差异真实（但属库级约定，双方都没违反论文） |
| **A20** `^` 语义 | vnpy 的 `pow1`（常数指数）**也是保号幂** ⇒ 支持本库默认选择；其 `pow2` 在「负底数 + 非整数指数」返回 0，而 101 因子里 `^` 的底数全是 `rank(...)`（非负）⇒ 分歧不触发 |
| A22/A23（缺失语义） | vnpy 用 `fill_null(0)` / null 传播，本库用 NaN / fmin-fmax ⇒ 差异只体现在**覆盖率**（§1.5.2），不改变共同有效格子上的取值 |
| — | 参照侧另有 **1 个实测 bug**（`quesval2` 条件取反）与 1 个保号幂之外的差异，记录在 `docs/deviations.md` §3.2（V11–V15） |
