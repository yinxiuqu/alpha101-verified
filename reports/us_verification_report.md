## 2. 取数与面板

* 来源：新浪 `US_MinKService.getDailyK`（JSONP），**162 只美股大中盘**，窗口 `2022-01-01 ~ 2024-12-31`；
* ⚠️ **限流教训**：首轮用 0.3 s 间隔，**一半请求被限流** ⇒ 只有 **80 只**落地；
  已把间隔改为 1.2 s + 失败重试 2 次（退避 5/15 s），工具支持断点续取。
  **本报告的验证以已落地的 80 只为样本**（如实说明：样本比计划小一半，原因是限流而非筛选）；
* 面板：**80 只 × 753 个交易日**（2022-01-03 ~ 2024-12-31）；
* 字段：`close/Open/high/low/volume/amount`，其中
  **`vwap = 成交额 / 成交量` 是真 VWAP**（不是 `(h+l+c)/3` 之类的近似）；
* 复权：免费源都是**未复权**价。拆股用**双条件**识别后做后复权 ——
  ① 相邻收盘价比落在简单整数比（到 20:1）±25% 内；② 成交量同步反向跳（放宽到 0.25~4 倍）。
  ⚠️ 本轮实测踩到两个坑，均已修：**只列到 10:1 会漏掉 20:1**（GOOGL 2022-07-18、AMZN 2022-06-06），
  **成交量判据过严会漏掉 10:1**（LRCX 2024-10-03 当日成交量只增 4.7 倍）。
  修正后：`|单日收益| > 35%` 的格子 **0 个**（修正前 3 个，全是漏检的拆股）。
  **分红不修**（<1% 的跳空识别不了）⇒ 本面板是「拆股已修、分红未修」，与 A 股面板（除权除息 hfq）口径不同。

## 3. 验证结果（真实美股数据）

| 检查 | 结果 |
|---|---|
| 面板契约（`validate_panel`） | ✅ 通过 |
| `vwap ∈ [low, high]` 自洽率 | **99.49%**（单位/复权合理性的自查） |
| 因子可跑数 | **82/101** —— 缺 `cap` 与 `ind_*` 的 19 个自动跳过（18 个 `IndNeutralize` + `alpha56`） |
| ±inf | **0 个** |
| 平均覆盖率 | **89.5%** |
| 时间截断一致性（PIT 金标准，抽样 12 个因子） | ✅ **全部通过** |
| **因子级差分 vs vnpy（82 个可比因子）** | ✅ **64 逐点一致 + 18 已归因 + 0 待查** |

因子级差分的归因构成（与合成面板 / A 股真实数据**完全一致**，说明结论不由数据源决定）：

* 参照侧 bug：`quesval2` 条件取反 —— **2 个**；
* 离散平局/数值病态经截面 rank 放大 —— **14 个**（机制已在 alpha45 上逐算子复算定位）；
* 覆盖差异经截面算子传播 —— **2 个**。

## 4. 未覆盖项（不假装完成）

1. **18 个 `IndNeutralize` 因子**：美股免费源没有行业字段（tushare 的 `classify` 是证券类型）⇒ 本轮无法覆盖；
   它们此前已在 **A 股真实数据**上验证（含三层行业正交性断言）；
2. **`alpha56`**：需要 `cap`（市值），免费源不提供 ⇒ 与 A 股面板上的验证互补；
3. **分红未复权**：见 §2；对**因子级差分无影响**（两侧吃同一份面板）；
4. 样本 80 只（限流所致）⇒ 截面类算子（`rank`/`scale`）的样本规模小于 A 股那轮的 120 只。
