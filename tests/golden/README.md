# golden 快照基线（M5 待建）

本目录用于存放 **golden 快照**：固定随机种子的小面板（如 5 只股票 × 250 天）上
101 个因子输出的冻结基线（数值/哈希），接入 CI 后任何无意改动（含 pandas/numpy
升级）立即暴露。对应设计文档 §6.6 / §7.2。

**当前状态：空。** 因子层（M2/M3）尚未实现，没有可冻结的输出。
按设计文档 §7.7 的顺序，golden 快照在 M5 生成；在快照入库前，
相关因子的验证状态一律不得标为 `verified`（§6.8 门槛 5）。

算子层（M1）不需要 golden 快照：每个算子都有**解析可算的期望值**与
**独立权威实现对拍**（scipy / pandas / statsmodels），比冻结快照更强。
